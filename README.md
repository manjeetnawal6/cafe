# Cabin Cafe Website

Responsive React + Vite + Tailwind website for Cabin Cafe, Rajiv Chowk, Delhi.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Before publishing
- Replace sample menu items and placeholder prices with the confirmed café menu. The menu communicates a price range of ₹30 to ₹500.
- Confirm the café's exact address and opening hours.
- Replace placeholder social links with official profiles.
- Update the phone number if required.

## Stack
React 18, Vite, Tailwind CSS 3, Lucide React.
